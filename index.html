คู่มือการใช้งาน

ส่องพระ AI — เครื่องมือคัดกรองเบื้องต้นด้วยภาพ ไม่ใช่เครื่องมือชี้ขาดแท้-เก๊

1. เพิ่มรูปพระแท้เข้าฐานข้อมูล

กด "+ เพิ่มรูปพระแท้" เลือกรูปได้ทีละหลายรูป (เลือกจาก Google Drive ได้ด้วย) ระบบจะถาม:

  1. ชื่อรุ่น/ชุด — ใช้แสดงในหน้าเทียบตำหนิ
  2. ราคา — เว้นว่างได้ถ้ายังไม่รู้ ใส่ทีหลังได้

รูปที่เพิ่มจะใช้ได้ทั้ง ฐานส่องพระ และ หน้าเทียบตำหนิ ในครั้งเดียว ไม่ต้องอัปโหลดซ้ำ

แตะรูปย่อในหน้าหลักเพื่อแก้ราคาทีหลังได้ทุกเมื่อ

2. วางรูปจากเว็บ (ไม่ต้องดาวน์โหลดก่อน)

  1. เจอรูปพระแท้บนเว็บ → กดค้างที่รูป → เลือก "คัดลอกรูปภาพ / Copy Image"
  2. มาที่แอป → แตะกล่องเส้นประ "แตะค้างตรงนี้..."
  3. แตะค้างอีกครั้งในกล่อง → เลือก "วาง / Paste" จากเมนูที่เด้งขึ้น

รูปจะถูกประมวลผลและเข้าระบบเหมือนเพิ่มไฟล์ปกติทุกอย่าง

3. ส่องพระแบบเรียลไทม์

กด "เริ่มส่องพระ" → อนุญาตใช้กล้อง → เอากล้องหลังส่ององค์พระให้เต็มกรอบ ระบบจะตัดพื้นหลังและครอปเฉพาะองค์พระให้อัตโนมัติก่อนเทียบเสมอ

  • วงพิมพ์ทรง — ความเหมือนรูปทรง/บล็อกกับรูปในฐานข้อมูลที่ใกล้เคียงที่สุด
  • วงโทนสีผิว — ความเหมือนโทนสี (ไวต่อแสงมาก ควรส่องใต้แสงขาวสว่างสม่ำเสมอ)
  • เขียว = 70% ขึ้นไป, แดง = ต่ำกว่า 70%
  • แถบราคา — โชว์ราคาของรูปที่จับคู่ได้ เทียบกับ "เกณฑ์ราคา" ที่ตั้งไว้ในหน้าหลัก
  • แถบซูม — ใช้เมื่อองค์พระเล็กเกินไปในจอเท่านั้น ไม่จำเป็นต้องซูมให้พอดีเป๊ะ เพราะระบบครอปให้อัตโนมัติอยู่แล้ว

เห็น % เข้าตา → กด 📸 เก็บภาพนี้ไว้เทียบตำหนิ ระบบจะหาว่าตรงกับรูปในฐานข้อมูลรูปไหนที่สุด แล้วเปิดหน้าเทียบให้อัตโนมัติพร้อม %

4. เทียบตำหนิแบบละเอียด

เข้าได้จากปุ่ม "🔍 เทียบตำหนิ" ในหน้าหลัก แล้วแตะรูปที่ต้องการ หรือมาจากการกด 📸 ในหน้าส่อง มี 3 โหมด:

  • เทียบคู่ — สองภาพเคียงกัน ลากนิ้วเลื่อนดู เลื่อน/ซูมพร้อมกันเสมอ
  • ภาพซ้อน — ซ้อนสองภาพทับกัน เลื่อนแถบความเข้มดูว่าเส้นพิมพ์ตรงกันไหม
  • หมุดตำหนิ — กด "➕ เพิ่มหมุดตำหนิ" แล้วแตะจุดบนรูปองค์ครู ตั้งชื่อจุด จากนั้นเช็คทีละจุดว่า "ตรง/ไม่ตรง" ได้

ในแท็บ "เทียบคู่" คลิก/แตะจุดที่สงสัยบนรูปฝั่งไหนก็ได้ครั้งเดียว ระบบจะซูมเฉพาะจุดนั้นของทั้งสองภาพ ปรับความสว่าง/โทนสีและสเกลขนาดให้ใกล้เคียงกันก่อนอัตโนมัติ แล้วคำนวณ % ความใกล้เคียงเฉพาะจุด ให้ทันที (ในแท็บ "หมุดตำหนิ" ต้องกดค้างแทน เพราะคลิกเดียวถูกใช้สำหรับปักหมุด)

อยากเน้นตำแหน่งตำหนิให้ชัดกว่าจุดเดียว กด "🎯 วาดวงกลมเน้นตำหนิ" แล้วลากบนรูปฝั่งไหนก็ได้จากจุดศูนย์กลางออกไปเป็นวงกลม ระบบจะวาดวงเดียวกันซ้อนบนทั้งสองภาพให้อัตโนมัติ พร้อมคำนวณ % เฉพาะพื้นที่ในวงนั้น วงจะเปลี่ยนเป็นสีเขียว/แดงตามผล กด "✕ ล้างวง" เพื่อลบแล้ววงใหม่ได้

ไม่มีรูปองค์ที่ตรวจสอบ? กด "เลือกรูปองค์ที่ตรวจสอบ" อัปโหลดรูปที่ถ่ายด้วยกล้องปกติ หรือรูปที่แคปหน้าจอมาได้เลย

5. เกณฑ์ราคาและสี

ตั้ง "เกณฑ์ราคา" ในหน้าหลัก — ตอนส่อง ถ้าราคาของรูปที่จับคู่ได้ไม่เกินเกณฑ์ = ตัวเลขสีเขียว เกินเกณฑ์ = สีแดง

6. สำรอง / กู้คืนข้อมูล

กด "⬇ สำรองฐานข้อมูลเป็นไฟล์" เป็นระยะ โดยเฉพาะหลังเพิ่มรูปชุดใหญ่ แล้วเก็บไฟล์ที่ได้ไว้ใน Google Drive ถ้าเปลี่ยนเครื่องหรือข้อมูลหาย กด "⬆ กู้คืนจากไฟล์สำรอง" เลือกไฟล์นั้น ข้อมูลกลับมาครบทันที (รวมราคาและหมุดตำหนิ)

7. ส่องจากหน้าจอคอม (เฉพาะคอมพิวเตอร์)

ถ้าเปิดจากคอมด้วย Chrome/Edge/Firefox จะเห็นปุ่ม "📺 ส่องจากหน้าจอคอม" เพิ่มมา ใช้ตอนกำลังดูไลฟ์ขายพระอยู่ในแท็บ/หน้าต่างอื่น กดแล้วเลือกแท็บ/หน้าต่างนั้นให้แอปวิเคราะห์แบบเรียลไทม์ได้เลย (ปุ่มนี้จะไม่แสดงบนมือถือ เพราะมือถือส่วนใหญ่ไม่รองรับความสามารถนี้) โหมดนี้มีของเสริมเฉพาะ:

  • ลากกรอบเลือกจุดวิเคราะห์เอง — ลากเมาส์บนภาพเพื่อเลือกตำแหน่งองค์พระแม่นๆ (แทนการครอปกึ่งกลางอัตโนมัติ) มีประโยชน์เพราะจอไลฟ์มักมีของรก (แชท/ปุ่ม UI) ทำให้ตัดพื้นหลังอัตโนมัติพลาดง่ายกว่าปกติ กด "รีเซ็ตกรอบ" เพื่อกลับไปใช้ทั้งภาพ
  • เก็บภาพได้หลายรูป — กด 📸 ได้เรื่อยๆ ระหว่างดูไลฟ์ (คนขายมักหมุนองค์ให้ดูหลายมุมเร็วๆ) ภาพจะสะสมเป็นแกลเลอรีด้านล่าง แตะรูปไหนก็ได้ทีหลังเพื่อส่งไปเทียบตำหนิ แตะ ✕ เพื่อลบรูปที่ไม่ต้องการ
  • คีย์ลัด Spacebar — กด Spacebar แทนการคลิกปุ่ม 📸 ได้ สะดวกเวลาต้องจับจังหวะเร็วๆ

⚠️ ข้อควรระวัง

  • ตัวเลข % คือความเหมือนของภาพเท่านั้น ไม่ใช่การยืนยันแท้-เก๊ พระเก๊ถอดพิมพ์เหมือนอาจได้คะแนนสูงได้
  • ระบบไม่สามารถบอกความเก่าถึงยุคได้
  • ถ่ายบนพื้นหลังสีเรียบ (ผ้ากำมะหยี่/พื้นขาว) แสงสว่างสม่ำเสมอ จะได้ผลแม่นที่สุด
  • ใช้เป็นตัวคัดกรองเบื้องต้น พระราคาสูงควรให้ผู้ชำนาญตรวจสอบก่อนตัดสินใจเช่าบูชาทุกครั้ง
  • ข้อมูลทั้งหมดเก็บอยู่ในเครื่องนี้เท่านั้น เปิดเครื่องอื่นจะเป็นฐานข้อมูลว่างใหม่ (ใช้ไฟล์สำรองย้ายข้อมูลได้)

ตัวเลขและการเทียบเป็นการเปรียบภาพกับฐานข้อมูลเท่านั้น พระเก๊ถอดพิมพ์เหมือนอาจได้คะแนนสูงได้
ระบบไม่สามารถยืนยันความเก่าถึงยุคได้ — ใช้คัดกรองเบื้องต้น ควรให้ผู้ชำนาญตรวจสอบก่อนเช่าบูชาทุกครั้ง
